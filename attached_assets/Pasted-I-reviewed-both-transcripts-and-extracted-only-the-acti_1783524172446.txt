## Priority order I recommend

**First priority:** security and blockers: admin Clerk/Replit auth, remove test credentials, fix Replit deployment/student profile loading, and re-enable password reset.

**Second priority:** core scholarship workflow: multi-step submission form, request pipeline alignment, upload preview/download, internal notes save, and full QA testing.

**Third priority:** UI polish: dashboard cleanup, students table cleanup, student profile/cards/sidebar redesign, archive color, save button alignment, and moving “Latest Submission: Paid”.

**Fourth priority:** admin data management: student import template, university import/export template, responsive admin view, and university/program/semester activation logic.
